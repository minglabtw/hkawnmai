# 開發日誌 — HKAWN MAI 學中文

## 專案概述

緬甸學習者專用的簡體中文學習閃卡 App。包含 HSK 1-6 共 7,419 條詞彙，每條含中文、拼音、緬甸文釋義、中文例句、例句拼音、緬甸文例句翻譯、語音音檔。

### 階段 6：PWA 開發與 iOS 優化（2026-05-12）

**目標**：PWA 上線、音頻架構確立、iOS 相容性修復

#### 音頻架構歷程

| 嘗試 | 結果 |
|------|------|
| GitHub Releases 直接 fetch zip | ❌ CORS 阻擋 |
| 同源 zip + JSZip 解壓 + IndexedDB | ❌ iOS 儲存卡住 |
| CI 自動解壓 → 部署到 Pages → 直讀單檔 mp3 | ✅ 成功 |

#### 手機版卡片佈局

- 從 3D perspective + transform 改為 CSS grid + display 切換
- 放棄 3D 翻轉動畫，改用 fade 切換（行動端穩定優先）
- 卡片正背面用 position:relative，回歸正常文件流
- 按鈕區 .ac 用 opacity + pointer-events 切換，永遠佔位
- 桌面版保留 3D 翻轉（>=768px）
- 移除 setCardHeight() JS hack

#### iOS 相容性修復

- AudioContext.resume() — iOS 聲音修復
- `viewport-fit=cover` + `env(safe-area-inset-top)` — 瀏海安全區域
- `env(safe-area-inset-bottom)` — 底部手勢條
- `100vh → 100dvh` — Safari Viewport 正確高度
- `.hd-icon` 熱區 28px → 36px（Apple HIG 建議 ≥44px）
- 狀態欄 `default → black-translucent`（沉浸式）

#### 間隔重複系統

- 8 級混合式排程（等級 0~7）
- 到期單字優先顯示
- 忘了→歸零重複、記得→級別加一、間隔遞增
- 每天最多學 10 個新單字
- 首頁顯示「📚 待複習 N 字」

#### 移除的功能

- 單字/完整下載模式選擇（對話框 + 設定 radio）
- JSZip CDN + IndexedDB 全部程式碼（~120 行）
- 下載按鈕及下載進度 UI
- 設定頁音頻管理區塊
- 5 個 word-only zip 檔案
- 3D 翻轉的 setCardHeight() 函式
