# 音頻解決方案

## 最終架構（2026-05-12）


CI 建置時解壓 → 同源直讀單檔 mp3

### 流程

zip 存入 repo data/（9 個 zip，總計 269MB）
→ GitHub Actions deploy.yml 中 unzip
→ 解壓為 14,838 個 mp3
→ 部署到 GitHub Pages（同源）
→ PWA 直接：new Audio('/hkawnmai/audio/0001.mp3').play()
→ APK 本機：new Audio('audio/0001.mp3').play()

### 優點

- JSZip 完全不需要
- IndexedDB 完全不需要
- 每次下載僅 8-25KB（單檔 mp3），不可能失敗
- iOS 完美支援（標準 HTMLAudioElement）
- 瀏覽器 HTTP Cache 自動處理重複播放
- 離線時 Service Worker 快取已播過的 mp3

### 方案演進（簡要）

1. GitHub Releases 下載 → ❌ CORS 阻擋（release-assets.githubusercontent.com）
2. 同源 zip + JSZip + IndexedDB → ❌ iOS 儲存卡住、48MB blob 記憶體問題
3. CI 解壓直讀單檔 → ✅ 最終方案

### 程式碼（音頻全部）

```
var IS_PWA = location.protocol === 'https:';
var AUDIO_BASE = IS_PWA ? '/hkawnmai/audio/' : 'audio/';

function playAudio(f){
  if(!f)return;
  new Audio(AUDIO_BASE + f).play().catch(function(){});
}
```
