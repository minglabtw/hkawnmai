# 音頻解決方案

## 問題概述

HKAWN MAI 學中文 包含 14,838 個 mp3 音頻檔案（7,419 詞 × 中文發音 + 例句發音），總容量約 300MB。

**兩個版本都有音頻需求：**

| 版本 | 音頻位置 | 方式 |
|------|----------|------|
| **Android APK** | 打包在 APK 內 | 本地 `audio/` 目錄，`new Audio('audio/0001.mp3')` |
| **PWA (GitHub Pages)** | 從網路下載快取 | 下載 zip → JSZip 解壓 → IndexedDB 快取 → blob URL 播放 |

PWA 版面臨的核心問題：**如何讓瀏覽器下載並解壓 300MB 音頻？**

---

## 方案演進

### 方案 A：GitHub Releases 直連下載（❌ 失敗）

最初嘗試直接從 GitHub Releases 下載 zip 檔案：

```
PWA (https://minglabtw.github.io/hkawnmai/)
  → fetch('https://github.com/.../release/.../audio-beginner.zip', {mode:'cors'})
  → HTTP 302 → release-assets.githubusercontent.com/...
  → ❌ 無 Access-Control-Allow-Origin 標頭
  → 瀏覽器擋住：CORS 跨域讀取失敗
```

**GitHub Releases 的 CDN 不允許跨域 JavaScript 讀取回應體。**

### 方案 B：同源託管（✅ 解決）

把 zip 檔直接放到 **repo 的 `data/` 目錄**，透過 **GitHub Pages 同源提供**：

```
PWA (https://minglabtw.github.io/hkawnmai/)
  → fetch('/hkawnmai/data/audio-beginner.zip')
  → 同源請求 ✅
  → HTTP 200 → 正常讀取 blob
  → JSZip 解壓 → IndexedDB 快取
```

#### Git 單檔限制

GitHub 限制單檔 push 不超過 **100MB**。需要拆分：

| 檔案 | 原大小 | 拆分 | 結果 |
|------|--------|------|------|
| `audio-beginner.zip` | 32MB | 不拆 | ✅ |
| `audio-intermediate.zip` | 85MB | 不拆（<100MB） | ✅ |
| `audio-advanced.zip` | 152MB | 拆 2 份 | 需拆分 |
| → `advanced-1.zip` | 78MB | 單字 4125-5772 | ✅ |
| → `advanced-2.zip` | 74MB | 單字 5773-7419 | ✅ |

```
│    → 如果是 advanced：先下載 part1，再下載 part2       │
│    → fetch(AUDIO_BASE + zipName)                     │
│    → response.blob()                                 │

│ 播放音頻                                              │
│  getAudioBlob('0001.mp3', callback)                  │

│    → URL.createObjectURL(blob)                       │
│    → new Audio(url).play()                           │
└─────────────────────────────────────────────────────┘
```

## 程式碼關鍵邏輯

### 音頻基底路徑

```js
var AUDIO_BASE = IS_PWA ? '/hkawnmai/data/' : 'audio/';
```

- **PWA**：指向 GitHub Pages 同源路徑 `minglabtw.github.io/hkawnmai/data/`
- **APK**：指向本機 `audio/` 目錄（打包在 APK 內）

### 下載流程

```js
function downloadZipPart(tier, url, partsIdx, loaded, total){
  fetch(url)                    // 同源請求，無 CORS
    .then(r => r.blob())        // 直接讀取 blob
    .then(blob => JSZip.loadAsync(blob))  // JSZip 解壓
    .then(zip => {
      // 遍歷 zip 內所有 mp3，存入 IndexedDB
      zip.forEach((path, file) => {
        entries.push(file.async('blob').then(b => ({name:path, data:b})));
      });
      return Promise.all(entries).then(ents => {
        var tx = audioDB.transaction('audio', 'readwrite');
        for(var i=0; i<ents.length; i++) tx.objectStore('audio').put(ents[i]);
        tx.oncomplete = () => { /* 下一包 / 完成 */ };
      });
    });
}
```

### 播放流程（PWA）

```js
function playAudio(f){
  if(!f) return;
  if(!IS_PWA){
    // APK：直接播放本機音頻
    new Audio('audio/'+f).play();
  }else{
    // PWA：從 IndexedDB 取出 blob URL 播放
    getAudioBlob(f, function(blob){
      if(blob) new Audio(URL.createObjectURL(blob)).play();
    });
  }
}
```

## 使用者體驗

```
開啟 PWA → 進入初級學習
  ├─ 首次使用 → 顯示 ⬇ 下載音頻 (32MB)
  │   點擊 → 進度條 → JSZip 解壓 → 快取完成
  │   下載按鈕消失 → 🔊 可正常播放
  │
  ├─ 切換中級 → 顯示 ⬇ 下載音頻 (85MB)
  │   點擊 → 同上流程
  │
  └─ 切換高級 → 顯示 ⬇ 下載音頻 (152MB 2 parts)
      點擊 → 下載 part1 → 完成 → 下載 part2 → 完成
```

### 容錯機制

- 下載失敗 → 顯示 **⚠ 下載失敗，重試** 按鈕
- 點擊播放時未下載 → 自動觸發下載
- 設定 → 音頻管理 → **清除快取** → 可重新下載

## 技術棧對照

| 元件 | 技術 |
|------|------|
| PWA 託管 | GitHub Pages（同源） |
| zip 解壓 | JSZip（CDN 載入） |
| 音頻快取 | IndexedDB（Blob 儲存） |
| 狀態記錄 | localStorage（h_audio_tiers） |
| 播放 | URL.createObjectURL + HTMLAudioElement |
| 音效 | Web Audio API（OscillatorNode） |
